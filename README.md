# Abba / Hermes HTML Library

Canonical public home:

https://abbabk.github.io/

This repository hosts public-safe HTML artifacts for Abba Bello Kanwa and Hermes.

## Publishing lane

- GitHub Pages is the permanent public home for polished HTML artifacts.
- here.now remains the fast preview and staging lane.
- Public pages must not contain raw private logs, secrets, credentials, private transcripts, internal system paths, or unsanitized Obsidian-derived material.

## Current seed

The first version indexes public here.now artifacts and defines the clean GitHub Pages route plan. Future passes can migrate individual artifacts into native routes such as `/mai-tsara/`, `/life-os/`, `/apps/`, `/query-patterns/`, and `/night-freedom/`.
